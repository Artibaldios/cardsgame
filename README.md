# Find the Killer

Find the hidden killer before five characters are eliminated. Each day, inspect a 2×2 group of characters or try to arrest one suspect, then move to the next day. The killer can eliminate nearby characters and shift rows or columns to stay hidden.

## Quick start

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Available scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run preview` — preview the production build locally
- `npm run lint` — run ESLint

Built with React, TypeScript, Vite, and Redux Toolkit.
